# 千与千寻：白龙受伤参考图

本目录包含 36 张原始参考图，未缩放、未压缩。

- `chihiro/08-haku-injured/refs/`：34 张分镜参考图。
- `chihiro/08-haku-injured/characters/`：千寻工装设定图、白龙龙形态设定图。
- `manifest.csv`：原图路径、文件大小及 SHA-256 校验值。

## 给 Work 的使用说明

请先读取本仓库的 manifest.csv，并逐张查看 36 张原图。不要仅凭文件名推测画面内容。角色设定图用于固定人物与龙的外观；refs 中的图片用于理解分镜、动作和场景关系。先报告是否成功读取全部图片，等待具体生成任务。如生图工具无法传入任务指定的全部参考图，请明确报告限制，不要自行删减参考图。

注意：原文件中有两个以 19 开头的分镜文件，均保留，不自行改号。
