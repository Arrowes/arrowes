请先读取本页索引和 manifest.csv，并逐张打开全部 30 张原图，报告实际读取成功的数量。每张 refs 剧照对应一张待生成的真人版照片，按 01–28 顺序处理；文件名是简短剧情提示，具体镜头、构图、动作、人物关系与场景细节以原图为准，不要只凭文件名生成。

千寻的真人外观与服装参考 characters/千寻工装设定图.png；白龙的龙形态外观参考 characters/白龙龙形态设定图.png。设定图用于固定外观，剧照用于固定分镜，保持跨图角色一致。重现剧照中的字幕或水印不是生成目标。先读图，等待用户的具体生成指令；如工具无法读取或传入所需参考图，请明确说明，不要自行减少参考图。
